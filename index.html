Quick Build Commands

# 1. Clone repository
git clone https://github.com/Shifrozy/ALGENZA-VideoGenerator.git
cd ALGENZA-VideoGenerator

# 2. Install dependencies
pip install -r requirements.txt

# 3. Build for YouTube (16:9 Landscape)
python cli.py build --aspect 16:9

# 4. Build for TikTok / Reels / Shorts (9:16 Vertical)
python cli.py build --aspect 9:16

# 5. Build all platforms simultaneously
python cli.py build --aspect all
